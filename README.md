# memory-game

A fast-paced memory challenge built with Flutter! Test your cognitive skills by memorizing and recalling letters hidden across a grid.

## 🎮 How to Play

1. **Reveal:** A specific number of tiles (e.g., 7) on an 8x8 grid will temporarily flip over, revealing hidden letters.
2. **Memorize:** You have a brief window of a few seconds to memorize the revealed letters before they flip back face down.
3. **Recall:** Type out all the letters you remember. The order doesn't matter, but accuracy does!

## 🚀 Features

* **8x8 Interactive Grid:** A responsive 64-tile board
* **Timed Mechanics:** Automated countdown delays for the memorization phase.
* **Unordered Input Validation:** Flexible scoring that checks if your typed input matches the revealed letters, regardless of the sequence.
